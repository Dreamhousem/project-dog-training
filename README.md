# 🐶 Платформа для обучения и дрессировки собак

🔗 **Доступ к сайту:** [dreamhousem.github.io/project-dog-training](https://dreamhousem.github.io/project-dog-training/)

## 📌 О проекте

Этот сайт – **экспертное решение в воспитании собак**. Он создан для владельцев питомцев, которые хотят научиться правильно содержать, дрессировать и корректировать поведение своих собак с помощью **гуманных методов**.

Сайт предлагает **курсы, консультации и индивидуальное сопровождение** от профессиональных кинологов.

## 🔥 Основные возможности

- 📚 **Курсы по воспитанию и дрессировке** (от базовых до специализированных)
- 👨‍🏫 **Онлайн-курсы, вебинары и консультации**
- 📍 **Интерактивная Google-карта** для удобного поиска оффлайн-локаций
- 📩 **Подписка на рассылку** с полезными материалами
- 📝 **Блог с полезными статьями**

## 🎨 UI/UX и адаптивность

Сайт адаптирован под **мобильные устройства** (2 break-point'а).  
Дизайн выполнен в **минималистичном стиле**, удобен для пользователей и включает интерактивные элементы.

## ⚙️ Технологии

- **HTML, CSS (адаптивная верстка)**
- **JavaScript (минимальное использование)**
- **Google Maps API (для встроенной карты)**

## 🛠 Интерактивные элементы

- 💬 **Форма обратной связи** с отправкой сообщений
- 📩 **Подписка на рассылку с подтверждением**
- 📜 **Выпадающие окна** при успешной отправке сообщений

## 🎓 О выпускном проекте

Этот сайт создан в качестве **выпускного проекта** курса **"Разработка веб-сайтов с использованием HTML, CSS и JavaScript"**.  
Основная цель – **применить полученные знания** на практике, отработать навыки адаптивной верстки, работы с JavaScript и интерактивными элементами.

Проект выполнен **как учебный**, дальнейшее развитие и поддержка не планируются.
